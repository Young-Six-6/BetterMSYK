# BetterMSYK

BetterMSYK 是“美师优课”Android 客户端的增强模块

> [须知！]
> 本项目不应被用于作弊、破坏数据等不道德或不合规用途。因使用模块导致一切问题与作者无关，作者不为模块使用造成的后果负责

## 运行要求

| 项目 | 要求 |
| --- | --- |
| Android | Android 12（API 31）及以上 |
| 目标应用包名 | `com.zdsoft.newsquirrel` |
| Xposed API | API 82 |
| 推荐框架 | LSPosed |
| 兼容框架 | 仅测试LSPatch 0.8 |

推荐搭配 LSPosed 进行使用。也尝试针对 LSPatch 进行了兼容处理，但不能保证成功运行。

## 功能概览

提供 25 项主要功能，模块各项功能均可单独控制。


- **关闭更新**：阻断应用更新，默认开启。
- **全局禁止缓存**：尽量禁止缓存内容。
- **多用户登录**：保存多组用户名、密码和设备序列号。
- **自定义设备序列号**：覆盖 `padLogin` 与 `anhuiPadLogin` 请求中的 `sn`。
- **隐藏注入常显**：无需点击头像即可直接显示隐藏入口。
- **显示模块日志**：在“关于平台”中显示模块日志入口。
- **音量触发**：在答题卡页面连续按三次音量下键触发自动回填。
- **强制开放学习项目**：忽略学校开通状态启用学习圈功能。
- **覆写用户服务协议**：在用户协议下附加模块协议。
- **调试编码生成**：在“关于平台”中提供日志编码生成。
- **使用系统选择器代替内置选择器**：上传作业图片时使用 Android 系统文件选择器。
- **上传文件替代录音**：对于需要录音的题目，允许选择MP3音频文件上传。
- **不进行作业用时限制**：忽略限时作业的客户端计时限制。
- **一键正确**：自动回填客观题答案。
- **未提交作业答案解析**：为未提交作业添加“答案解析”入口。
- **显示作业 ID**：在作业列表显示homeworkid。
- **自定义开屏图片**：选择启动页图片。
- **精简模式**：提供简洁的页面。
- **显示身份**：仅修改界面展示的姓名、学号、学校和年级，不修改服务器账号资料。
- **允许强制退出**：解除课堂及部分作业页面禁止中途退出限制。
- **禁止 Launcher 交互**：阻止目标应用尝试与领创通信。
- **OSS ToolKit**：OSS 文件工具，支持读取、预览、选择和替换材料。
- **id登录**：使用userid登录账号。
- **显示ID**：显示Userid。
- **显示 Unit ID**：在“我的”页面显示并支持复制当前账号的 unitId。

## 打开模块入口

默认情况下，模块入口不会一直显示：

1. 打开应用的“我的”页面。
2. 连续点击头像 7 次。
3. 页面将显示“音量触发”“OSS ToolKit”和“模块设置”等入口。

启用“隐藏注入常显”后，无需再次点击头像。

## 安装与启用

### LSPosed

1. 安装构建得到的 BetterMSYK APK。
2. 在 LSPosed 中启用模块。
3. 将 `com.zdsoft.newsquirrel` 加入模块作用域。
4. 强制停止并重新启动目标应用。

### LSPatch

1. 推荐使用 LSPatch 0.8 分支，使用 BetterMSYK 修补目标 APK。
2. 安装修补得到的 APK。
3. 若个别功能异常，先开启模块日志，再附带框架版本与日志反馈，使用 LSPatch 框架的issue可能会延后处理。
